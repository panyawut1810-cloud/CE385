1. ex1-profile.js — ตัวแปรและการแสดงผล (Variables & Template Literals)
แนวคิดหลัก: ฝึกการประกาศตัวแปร (const), การคำนวณตัวเลขพื้นฐาน และการแสดงผลข้อความหลายบรรทัด
รายละเอียดการทำงาน:ประกาศตัวแปรเก็บข้อมูล 5 อย่าง ได้แก่ ชื่อ, รหัสนักศึกษา, อายุ, สาขา, จำนวนวิชาคำนวณปีที่จะจบการศึกษา: graduationYear = currentYear + remainingYears (2569 + 2 = 2571)ใช้ Template Literals (เครื่องหมาย Backtick ` ร่วมกับ ${}): ช่วยให้พิมพ์ข้อความแบบเว้นบรรทัดและใส่ตัวแปรแทรกเข้าไปได้ง่าย โดยไม่ต้องใช้เครื่องหมาย + ในการต่อสตริง

2. ex2-types.js — ชนิดข้อมูลและการแปลงค่า (Data Types & Type Conversion)
แนวคิดหลัก: เข้าใจพฤติกรรมของ Data Types ใน JavaScript, คำถามเชิงทฤษฎี และการแปลงข้อมูล (Type Coercion)
รายละเอียดการทำงาน:
    ส่วนที่ 1: ใช้ typeof เช็กชนิดข้อมูลพื้นฐาน 6 ตัว (string, number, boolean, undefined, null, Array)
    ส่วนที่ 2 (ทฤษฎีที่มักออกสอบ):typeof null จะได้ "object" — นี่คือ Bug ประวัติศาสตร์ตั้งแต่ยุคแรกของ JavaScript ที่แก้ไม่ได้เพราะจะกระทบเว็บเก่าๆ ทั่วโลกNaN (Not a Number) มีชนิดข้อมูลเป็น "number" (หมายถึง "ผลลัพธ์การคำนวณทางตัวเลขที่ล้มเหลว") เช็กได้โดยใช้ Number.isNaN()
    ส่วนที่ 3 (การแปลงชนิดข้อมูล):แปลง String "20" ให้เป็น Number ด้วย Number("20") เพื่อนำไปบวกเลขได้จริง (ถ้าไม่แปลง จะกลายเป็นการต่อข้อความ "20" + 5 = "205")ใช้ .toFixed(1) เพื่อจัดฟอร์แมตตัวเลขทศนิยมให้เหลือ 1 ตำแหน่งเปรียบเทียบ === (Strict Equality): "20" === 20 เป็น false เพราะคนละ Type แต่ Number("20") === 20 เป็น true

3. ex3-calculator.js — การคำนวณสัดส่วนและเป้าหมาย (Mathematical Operations)
แนวคิดหลัก: ใช้สูตรเทียบบัญญัติไตรยางศ์คำนวณคะแนนเก็บ และหาผลต่าง
รายละเอียดการทำงาน:
    1.กำหนดค่าคงที่เกณฑ์คะแนน (WORKSHOP_MAX_RAW = 60, WORKSHOP_WEIGHT = 20) เพื่อป้องกันการใส่ Magic Number (ตัวเลขลอยๆ) ในโค้ด
    2.คำนวณคะแนน Workshop: นำคะแนนดิบหารคะแนนเต็ม แล้วคูณด้วยน้ำหนักจริง (48 / 60) * 20 = 16 คะแนน
    3.รวมคะแนน: นำคะแนน Workshop ที่แปลงแล้วไปบวกกับคะแนนส่วนอื่น (เข้าเรียน 9 + โปรเจกต์ 17 + มิดเทอม 15 + ไฟนอล 24) รวมได้ 81 คะแนน
    4.คำนวณเป้าหมาย: เอาคะแนนเป้าหมาย (80) ตั้ง ลบด้วยคะแนนรวม 80 - 81 = -1 (หมายถึงได้คะแนนเกินเป้าหมายมา 1 คะแนน)

4. ex4-grade.js — เงื่อนไขและการวนลูป (If-Else & Loops)
แนวคิดหลัก: การใช้ if-else if-else ตัดเกรดอย่างมีลำดับขั้นตอน และตรวจสอบข้อมูลนำเข้า (Data Validation)
รายละเอียดการทำงาน:
    1.Validation First: ตรวจสอบก่อนว่าคะแนนอยู่ในช่วง 0–100 หรือไม่ ถ้า < 0 หรือ > 100 ให้เด้งเตือนทันที เพื่อป้องกันข้อมูลขยะ
    2.เรียงลำดับเงื่อนไข: ต้องเรียงจาก มากไปน้อย (>= 80 -> >= 75 -> ...) เพราะหากเรียงจากน้อยไปมาก เช่น เช็ก >= 50 ก่อน คนที่ได้คะแนน 85 จะหลุดเข้าไปติดเกรด D ทันที
    3.การทดสอบ: ใช้ for...of วนลูปเช็ก array testScores ซึ่งครอบคลุมทั้งคะแนนขอบเขต (Boundary values เช่น 80, 79, 0) และคะแนนที่ผิดปกติ (-5, 120)

6. ex6-login.js — ลำดับความปลอดภัยของการตรวจสอบสิทธิ์ (Security Sequence)
แนวคิดหลัก: การวางระบบ Authentication และ Authorization ตามลำดับมาตรฐานความปลอดภัยรายละเอียดการทำงาน:
Step 1: Authentication (พิสูจน์ตัวตน) — ตรวจ Username และ Password ก่อนเป็นอันดับแรก เพื่อยืนยันว่าผู้ใช้คือคนที่กล่าวอ้างจริงหรือไม่
Step 2: Account Status Check — ตรวจว่าบัญชีถูกระงับ (isActive === false) หรือไม่
Step 3: Business Logic Rule — ตรวจเงื่อนไขเพิ่มเติม เช่น อายุต้องไม่ต่ำกว่า 18 ปี
Step 4: Authorization (ตรวจสอบสิทธิ์) — เมื่อผ่านทุกด่านแล้ว ค่อยมาแยกแยะบทบาท (role) ว่าเป็น "อาจารย์" หรือ "นักศึกษา" เพื่อกำหนดสิทธิ์การใช้งาน

เหตุผลทางความปลอดภัย (คำตอบท้ายข้อ):
ทำไมต้องตรวจ User/Pass ก่อน Role?
 ตอบ ต้องพิสูจน์ตัวตนให้แน่ชัดก่อน ถึงจะไปตรวจสอบสิทธิ์ได้ หากไม่ตรวจตัวตนก่อน ใครก็อาจสวมรอยเข้ามาเช็กสิทธิ์ระบบได้
 
 ถ้าย้ายตรวจ "อายุ" ขึ้นไปข้อแรกจะเกิดอะไรขึ้น? 
 ตอบ เกิดปัญหา Information Leakage เช่น ผู้ไม่หวังดีสุ่มกรอกข้อมูล ระบบจะเผลอบอกว่า "อายุไม่ถึง"ทำให้เขารู้เงื่อนไขการทำงานภายในระบบทั้งๆที่เขายังไม่ได้ใส่รหัสผ่านที่ถูกต้องเลยด้วยซ้ำ
